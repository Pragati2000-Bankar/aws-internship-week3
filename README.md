# AWS-Internship–Week 3

This project covers hands-on AWS practice, including VPC networking, public and private subnets, EC2 instances, RDS MySQL database connectivity, AWS Lambda, API Gateway integration, and CloudWatch monitoring.

**Skills:** AWS, VPC, EC2, RDS MySQL, Lambda, API Gateway, CloudWatch, Python, SQL.

**Outcome:** Learned to configure secure cloud networking, connect a database to EC2, deploy a serverless API, and monitor AWS resources.
